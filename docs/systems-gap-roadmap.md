## 갭 — 우선순위순

### P1: 첫 세션 인상 (구매 결정 구간)
1. **튜토리얼 시퀀스** — 현재 가이드 퀘스트 카드 1줄뿐. 첫 5분 유도(사냥→강화→돌파→가챠→전직 예고) 스텝 팝업+하이라이트. *신규 코드: TutorialService + 오버레이*
2. **강화 연출** — 성공/실패 이펙트, 등급업 빛기둥, 스타포스 단계 표시. *기존 FX 프레임 재활용*
3. **재화 획득 연출** — 카운트업 트윈, 보상 팝업 코인 버스트 (G 잔여)

### P2: 리텐션 루프
4. **일일 미션 보드** — 일일 5종(사냥 N마리/강화 N회/던전/아레나/출석) + 주간 보상 상자. *MissionService + 이벤트 모달 탭 추가 — 기존 카운터(OnMobKilled 등) 후킹*
5. **업적 시스템** — 누적 마일스톤(처치 수/스테이지/소환 수) + 칭호. *AchievementService*
6. **몬스터/장비 도감(컬렉션)** — 수집 보너스 스탯. TplArt 일러스트 재활용. *CollectionService + 모달*
7. **복귀/연속 접속 보상** — 연속 출석 배수, 미접속 복귀 우편

### 실기기 플레이테스트로 잡은 버그 (Unity MCP 실행 검증)
- 🐞 **환생이 실제로 초기화되지 않던 버그** — `RebirthService`가 PlayerGrowth/StageProgress를
  `Destroy` + `AddComponent`로 되살렸는데, 두 클래스의 Awake 싱글턴 가드가
  `Destroy(gameObject)`를 호출해 **서비스 루트 전체를 파괴할 위험**이 있었고 실제로는
  레벨·스테이지가 재시작 전까지 그대로였다. → 두 클래스에 `ResetForRebirth()`를 추가해
  제자리 초기화로 변경. 같은 프레임에 Lv46→1, 스테이지 51→1 반영 확인.
- 🐞 **세력 모달이 다시 그려지지 않던 버그** — 입문 후에도 '입문' 버튼이 남아 재선택 시
  성향이 초기화됐다. → `FactionModal.Refresh`에 재빌드 연결(상태 변화 시에만 재구성).
- 🐞 **환생 모달 정보칩이 비어 있던 버그** — `InfoChip`은 레거시 `UI.Text`를 반환하는데
  `TMP_Text`로 찾아 항상 null이었다. → 타입 교정.
- 🐞 **버튼이 195px로 부풀던 버그** — `Image`가 `ILayoutElement`라 스프라이트 원본 높이가
  preferredHeight로 새어들었다. `ButtonBase`가 minHeight만 넣고 preferredHeight를 비워둔 탓.
  → 기본 preferredHeight 56 지정(`UiKit.Fix` 호출 시 덮어씀). 전 화면 버튼 높이 재검증 완료.
- 🐞 **어두운 모달 위 어두운 글씨** — 세력/환생 화면이 `TextPrimary/Secondary`(어두운 색)를
  써서 남색 배경에서 안 보였다. → 밝은 색으로 교체.

### 성능 대수술 (10연차 10초 멈춤 / 목록 스크롤 렉)
원인이 전부 하나였다: `RefreshAll`이 서비스 이벤트마다 동기 호출되고, 매번 카드 36장
(≈790 GameObject)을 전부 파괴·재생성했다. `Destroy`가 프레임 끝 처리라 같은 프레임에
40번 겹치면 카드가 1,400장까지 누적된다.
- `RefreshAll` → 더티 플래그 + `LateUpdate`에서 **프레임당 1회**만 실제 갱신
- `ClearChildren()` — `SetParent(null)` 후 Destroy (지연 파괴 누적 차단), 6곳 적용
- 10연차 `_batching` — 마지막에 한 번만 `Save()`+`OnChanged` (PlayerPrefs.Save는 동기 디스크 쓰기)
- `GrowArt.Load` 스프라이트 캐시 (기존엔 카드마다 `Resources.LoadAll` 호출)
- **결과: 무기 10연차 10,000ms+ → 20ms, 동료 25ms, 23화면 순회 771ms**

### 에셋 일원화 2차
- **장비 아이콘** → 키트 `Pictoicon_Sword/Helmet/Armor/Ring/Cloth/Shoes` 복사·연결
- **장착 슬롯** → 무기창과 같은 `HeroCard`로 표시(등급 프레임·레벨 배지·별)
- **장착 미리보기 캐릭터** → `UiKit.Fill`로 늘려 세로로 찌부러지던 것을 원본 비율 고정으로 수정
- **동료 이미지 통일** — 필드 동료는 하드코딩 프리셋, 동료창은 TplArt 수채화라 서로 딴판이었다.
  `CompanionArt`(신규)가 동료→프리셋 매핑과 프리셋 리그 렌더 초상화를 캐시해 **양쪽이 같은 그림**을 쓴다.
- **탭 마름모 현상** — `Menu_TopBtn_Focus`는 세로 9슬라이스가 없어(y:0,w:0) 탭 높이로 늘리면
  찌그러진다. 양쪽 상태 모두 `Menu_TopBtn`을 쓰고 색으로만 구분.
- **스크롤 하드 클리핑** → `RectMask2D.softness`로 위아래 부드러운 페이드 (모달 27곳)
- **엘리트 소환/소환레벨** → 장비창에서 메인 HUD의 HP/MP 왼쪽으로 이동
