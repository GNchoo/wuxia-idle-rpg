## 재질 티어 축 (전 무기 공용) [俠]

목/죽 → 철 → 강 → 정강 → 백련강 → 한철(청백·냉기) → 현철(검은 광택) → 오금 → 운철(별빛) → 신병(발광)

## 세력별 시각 규칙 (아트 디렉션)

| | 정파 | 사파 | 마도 |
|---|---|---|---|
| 색 | 백·청·남·회 (저채도 **고**명도) | 흑갈·탁한 적 (저채도 **저**명도) | 흑 + 진홍/자주 (**고채도 강대비**) |
| 실루엣 | 좌우대칭, 수직, A라인 | 비대칭, 한쪽 어깨 노출 | 과장 — 긴 소매, 높은 깃, 각진 어깨 |
| 재질 | 무명·모시·비단 (무광) | 가죽·모피·거친 마 | 광택 비단·흑철·보석 |
| 문양 | 태극·팔괘·매화·구름 | 없음 (문신·흉터) | 해골·뱀·혈문 |
| 무기 | 검·곤·불진·선장 | 도·부·편 | 연병기·암기·기형도 |

**소림 승복은 치의(緇衣) = 검은빛 도는 회색** [史]. 밝은 주황은 남방 상좌부 색이라 틀림.

## 부위별 명칭 (아이템 네이밍용)

- **머리**: 두건 → 망건 → 유건/죽립 → 속발관(나무→뿔→은→옥) → 도관/연화관
- **상의**: 단타(서민 활동복) → 경장 → 장삼 → 도포 → 쇄자갑 → 두정갑 → 산문갑 → 명광개
- **하의**: 무명 바지 → 행전(조선)/방퇴(중국) → 각반 → 전군(戰裙)
- **신발**: 짚신 → 미투리 → 천층저포혜(무술화 원형) → 박저쾌화(무협화 원어) → 목화
- **장신구**: 나무 요패 → 놋쇠 대구 → 은 요패 → 옥패 → 영패 → 호부

## 검 부위 명칭 (파츠 분리용)

검신(劍身) / 호수(護手, 코등이) / 검병(劍柄, 자루) / 검수(劍首, 폼멜) / **검수(劍穗, 술)** / 검초(劍鞘, 칼집)

> 폼멜과 술이 한글 독음이 같으니 데이터는 `pommel` / `tassel` 로 분리할 것.
> 술은 실존 [史]이며 **문파 식별 컬러코드**로 쓰기 좋다(무당 청, 화산 홍).

## 조사자가 확답 못 한 것

- 검수(술)의 실전 기능 — 무술계 통설은 있으나 1차 사료 미확인
- 착용형 조(爪)·철장갑의 중국 고증 — 인도 바그나크와 혼동 가능성
- 쌍절곤의 고대 중국 기원 — 논쟁적
- 화산파·아미파 검술 체계 — 현재 이미지는 대부분 20세기 소설 창작
