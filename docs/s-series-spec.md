## 실행 계획

### S1. 사냥 화면 완성 (물약·스킬독 UI)
- **자동 물약**: HP가 임계(기본 40%) 아래로 내려가면 자동 사용, 쿨타임 30초.
  보유 개수 제한(물약 아이템화: 골드 상점 구매 + 드랍). 수동 탭도 유지(쿨 공유).
  버튼에 쿨타임 라디얼 + 보유 수 뱃지.
- **스킬독 재구축**: 민짜 사각형 4개 → 키트 원형 슬롯 프레임 + 쿨타임 라디얼 필
  + 스킬 아이콘(Q2 전용 아트) + 남은시간. 점프 버튼도 같은 스타일.

### S2. 서브퀘스트 (연쇄 진행형)
- QuestService: 순차 퀘스트 체인 — "몬스터 N마리 → 강화 N회 → 스테이지 도달 →
  소환 N회 → 세력 입문 → ..." 무한 반복 사다리(회차마다 목표·보상 상승).
  키우기류 표준: 화면 상단 상시 노출 카드 1장 + [완료] 시 즉시 보상 + 다음 퀘스트.
- 가이드 퀘스트 카드 자리를 공유 (튜토리얼 종료 후 서브퀘스트가 그 자리를 이어받음).
- 진행 카운터는 기존 이벤트(OnMobKilled, 강화, 소환, 레벨업) 후킹 — DailyMission과 동일 패턴.

### S3. 필드 드랍 시스템
- DropService: 몹 처치 시 확률 드랍 — 골드 외에 장비조각/물약/유물조각.
  챕터(사냥터)별 드랍 테이블: 상위 챕터일수록 상위 티어 확률↑.
  장비 드랍은 **내 레벨±5 구간 + 현재 직업 착용 가능 종류**로 필터.
- 드랍 연출: 필드에 아이템이 튀어오르고 자동 흡수(기존 FX 풀 재활용).

### S4. 플레이어 캐릭터 아트 상향 — ✅ 완료 (2026-08-16)
채택안: 리그 신규 제작 대신 **'못생김'의 병목 슬롯 교체** (검증된 본 굽기 파이프라인 재사용).
- Face(두상 라인아트)·HairTop(상투+비녀)·HairBack(백리본 꼬리) 전용 파츠 제작·리깅.
- `ApplyHeroLook`: 히어로·프리뷰 전용 — 콧수염·턱수염 자동 제거, 모자 착용 시 윗머리
  숨김(SP1 SlotHidingItems 규칙 재현). 적·동료는 SP1 얼굴 유지 → 플레이어가 확실히 구분됨.
- 검증: 얼굴이 원본 머리 파츠와 두 자세에서 좌표 완전 동일(픽셀 동행), HUD 초상화 반영.
- 제작 중 잡은 함정 2건: ①사실 비율 옆얼굴로 나옴 → "원형, 가로=세로" 강제 프롬프트
  ②내부가 어두운 색으로 칠해짐 → 검정 획만 남기는 후처리 (`sum(rgb)<150`).
- 선택 확장(후순위): 세력·직업별 헤어 변형 (같은 파이프라인, face/hairtop 파일 추가만).

## 검증 규칙 (매 단계)
1. 컴파일·플레이 콘솔 에러 0
2. 신규 화면 스크린샷 + 실동작 확인 (표본이 아니라 흐름 전체)
3. 이전 시스템과 충돌 확인 (세이브 키 겹침, 이벤트 이중 후킹, UI 자리 경합)
4. 커밋 단위 = S 단계 1개
