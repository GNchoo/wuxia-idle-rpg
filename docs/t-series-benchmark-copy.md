## 실행 순서 (임팩트 순)

### T1. 수련 시스템 (벤치마크 '용사의 힘' 카피) — 최우선
- 재화 2종 신설: **수련 증표**(단계 강화용), **명성 훈장**(어빌리티 리롤용)
- 8종 트랙: 일반뎀% · 보스뎀% · 크리확률 · 크리뎀 · **공격속도** · 경험치획득 · MP회복 · 방어관통
  - 트랙별 단계 내 레벨 존재, **8종 전부 만렙 → 다음 단계**(벤치마크 '모든 수치를 다 채우면 다음 단계' 구조)
- 어빌리티 3슬롯: 랜덤 옵션(위 8종 풀), 훈장으로 리롤, 리롤 누적 시 고급 옵션 등장률↑
- 수급: **수련장 던전** 신설(T4 열쇠제 이전엔 기존 2회/일 규칙) + 업적/퀘스트 소량
- 배선: `GetAttackSpeedPct()` 성장화, 크확/크뎀/OutgoingMul/XpMul/방관 연동
### T2. 에디셔널 잠재 + 잠재 등급 차등
- 스타포스 12성↑ 슬롯에 에디셔널 잠재 해금 — **애디셔널 큐브 소비처** (데드 재화 해소)
- 잠재 등급 6단계 차등 확률(6% → 0.21% 스케일), 파괴 문턱 15성→20성, 하락 13성 유지
### T3. 보유 효과 + 도감 UI
- 무기: 보유 무기 전부가 ATK% 소량 기여(각성·등급 비례) — 기존 HoldScore를 실스탯화
- 장비: 슬롯 rarity 누적 보유 보너스
- 도감·보유효과 열람 UI (메뉴)
### T4. 던전 열쇠제 + 수련장
- 열쇠 일 3회 충전·10 누적, 던전 4종(기존 3 + 수련장), 광고로 열쇠 1회/일
### T5. 전직 4차(10/30/60/100) · 월드보스 20단계 · 길드 스킬 — ✅ 완료 (2026-08-16)
- 전직: 3차 60(독사·도사, 배율 상향) / 4차 100(야살 1.25배). 1·2차는 기존 유지
  (세력 입문이 Lv6에 1차를 자동 배정하는 우리 구조 존중 — 벤치마크의 Lv10과 다른 부분).
- 월드보스: 단계제 1~20, HP ×1.3^단계, 클리어 시 단계 영구 +1, 보상 단계 비례.
- 길드 스킬: 개인 연구 3종(합격진 공격%/호신강기 체력%/재물 분배 골드%),
  골드 소모, 상한 = 길드Lv/2+1 — 길드가 처음으로 전투에 기여.

**T1~T6 전 단계 완료.**
### T6. 정합 청소
- CP에 OutgoingMul 반영, SP 5/레벨·25/등급 정합, 사문화 수치 4건, 룬 융합 스텁 숨김
