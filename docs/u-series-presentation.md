# U 시리즈 — 프레젠테이션·콘텐츠 완성도 (2026-08-17)

유저 진단: "실기기 테스트를 하기엔 그래픽·UI가 한참 부족하다. 맵은 줄 2개,
마을도 없고, 상점 UI 부족, 출석·이벤트 같은 상용 게임 요소가 많이 부족하다."

시스템(S·T)은 완성 — 이번 시리즈는 **보이는 것**을 상용 수준으로 끌어올린다.
아트는 기존 파이프라인(Grok 생성, 아트 정책 예외 6종) 재사용.

## U1. 전장 지형 아트 — "줄 2개" 해소 (최우선)
- 현재: FieldWorldStage.EnsurePlatforms가 흰 스프라이트 바 2개(갈색 틴트).
- 목표: 무협 지형 플랫폼 — 몸통 타일(가로 반복) + 윗면 능선 + 양끝 마감.
  Grok으로 바이옴 톤별 생성(숲/암굴/한랭 — 챕터 그룹당 1종, 시작은 공용 1종+틴트).
- 바닥 지면도 동일 처리. 층마다 소품(바위·풀·등불·깃발) 랜덤 데코.
- 카메라 고정이라 parallax는 무의미 — 대신 부유 입자(먼지·꽃잎) ambient.

## U2. 마을(강호 거점) 화면 — 콘텐츠 허브
- Grok 무협 마을 전경 배경 + 건물 진입: 객잔(상점) · 대장간(장비) ·
  수련장(수련) · 표국(우편) · 방(도감/업적) · 게시판(퀘스트/이벤트).
- 기존 모달로 라우팅하는 허브 화면. HUD에 '마을' 버튼.

## U3. 상점 전면 개편
- 배너(핫딜/신상품 캐러셀) + 카테고리 카드형 상품 + 추천 상품 강조.
- 구매 연출(상자 열기 플래시), 가격 대비 가치 표기(x% 이득).

## U4. 출석·이벤트 고급화
- 출석판: 10일 나열 → 달력형 14일 + 7·14일 대형 보상 강조.
- 이벤트 센터: 배너 캐러셀 + 기간제 이벤트 1종(오픈 기념 7일 성장 미션).

## U5. 첫인상
- 타이틀 화면(무협 일러스트 + 게임명 로고 + 터치 투 스타트).
- 로딩/화면 전환 페이드, 챕터 진입 연출.

## 검증 규칙
각 단계: 실플레이 스크린샷 비교(전/후) → 유저 스크린샷 기준으로 재검 → 커밋 1개.
