# Adapters (에셋 재사용)

- `TemplateFeatureHost` — SAMPLETEXT 매니저 바인딩 (GameScene 전투 제외)
- `WalletAdapter` — Gold/Gem ↔ CurrencyWallet
- `InventoryAdapter` — Inventory 6슬롯 미러
- `WeaponSummonAdapter` / `CompanionAdapter` — HeroChest 확률
- `SkillAdapter` — Skills+Talent
- `ShopAdapter` — 상점·모의 IAP

갭(신규): `SlotEnhanceService`, `EliteSummonService`, `PassService`, `MembershipService`
