# SP1 착용 파츠 실측 규격

캐릭터가 **이미 들고 있는** 파츠(`WeaponR_Weapon_Fixed_0001~0021`, 21종)를
`Wuxia_Lib` 에서 PNG로 뽑아 잰 값이다. 새로 만드는 착용 스프라이트는 이 표에 맞춘다.
추측한 값이 아니라 측정값이므로, 여기서 벗어나면 손에서 빠지거나 크기가 어긋난다.

## 측정 결과

| 항목 | 값 |
|---|---|
| 주축 각도 | **-30°** (21종 중 15종이 -27~-33, 나머지는 도끼·낫처럼 머리가 큰 것) |
| 방향 | 날·머리가 **좌상단**, 자루가 우하단 |
| 캔버스 | 알파 **타이트 박스** (정사각 아님) |
| 가로:세로 | 1.17 ~ 1.73 (중앙값 약 1.45) |
| 피벗 | 정중앙 (0.5, 0.5) = 타이트 박스의 중심 |
| PPU | 100 |
| 외곽선 | **순검정 (0,0,0)** — 경계 픽셀 100%가 검정. 긴 변의 약 1/48 두께 |
| 셰이딩 | 플랫 셀 셰이딩 (그라데이션 거의 없음) |

## 크기 (긴 변, px)

| 종류 | 원본 예 | 우리 목표 |
|---|---|---|
| 단검·소형 병기 | 0001=85, 0008=68, 0017=106 | **105** (기병) |
| 한손 검·도·도끼 | 0007=145, 0013=136, 0014=173 | **150** (검·도) |
| 창·곤·낫 | 0004=201, 0019=206, 0020=203 | **205** (창곤) |
| 완갑·소형 | 0008=68, 0012=89 | **90** (권갑) |

## 화풍도 규격이다 (프롬프트에 넣는다)

크기·방향만 맞추고 화풍을 안 맞추면 손에 든 무기만 혼자 논다. 실제로
페인터리하게 뽑았더니 셀 셰이딩 캐릭터 위에서 붕 떴다. 아래를 프롬프트
(`docs/equip-icon-prompts.json` 의 `styleWear`)에 그대로 박아 넣는다.

- 실루엣 외곽 + **내부 부품 경계까지** 두꺼운 순검정선 (원본은 불투명 픽셀의 30%가 검정)
- 재질당 2~3톤 **플랫 셀 셰이딩**, 그라데이션·질감·반사·광휘 전부 금지
- 저채도 팔레트: 나무 `#886633`, 강철 `#7D8686` / 그림자 `#51544F`
- 150px에서 읽히는 단순·두툼한 실루엣

측정으로 검증한다 — 새로 뽑은 검의 검정계열 비율 27.9% (원본 ~30%),
경계 검정 비율 64~69%.

## 생성물을 맞추는 법

AI 생성물은 세로로 서 있다(끝이 위). **반시계 +60°** 돌리면 끝이 좌상단으로 가서
원본과 같은 축(-30°)이 된다. 이전에 -60°로 돌려 놨더니 좌우가 뒤집혀,
캐릭터가 적을 등지고 무기를 뒤로 뻗은 모양이 됐다.

```bash
python tools/fit_wear.py Assets/_Project/Resources/WearParts
```

인자 없이 돌리면 파일명으로 종류를 알아내 위 표의 크기·회전·외곽선을 적용한다.

## 다시 뽑는 법

```csharp
// Wuxia_Lib 의 원본 라벨(_0001~)을 RenderTexture 경유로 읽어 PNG 저장.
// PSB 산출 텍스처는 isReadable=false 라 GetPixels 가 실패한다 → Graphics.Blit 로 우회.
Graphics.Blit(sp.texture, rt); RenderTexture.active = rt;
tex.ReadPixels(new Rect(sp.rect.x, sp.rect.y, w, h), 0, 0);
```
