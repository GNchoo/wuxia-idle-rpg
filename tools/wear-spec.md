# 착용 파츠 제작 규격서

새로 뽑을 때 이 표만 보고 만들면 된다. 전부 원본 실측값이다
(무기 21종 · 방어구 39종을 PNG로 뽑아 잼).

## 0. 모든 파츠 공통

| 항목 | 값 |
|---|---|
| PPU | **100** |
| 피벗 | **정중앙 (0.5, 0.5)** — 그림의 무게중심이 캔버스 중앙에 오게 타이트 크롭 |
| 캔버스 | 알파 타이트 박스 (정사각 패딩 금지) |
| 외곽선 | 순검정, 긴 변의 약 1/48 |
| 셰이딩 | 재질당 2~3톤 플랫. 그라데이션·질감·반사·광휘 전부 금지 |
| 팔레트 | 나무 `#886633`, 강철 `#7D8686` / 그림자 `#51544F` (저채도) |
| 배경 | 크로마키 마젠타 `#FF00FF` 단색 |

**⚠️ 본 가중치**: 방어구는 PNG만으로는 애니메이션을 못 따라간다.
`IdleMvp/아트/무협 방어구 본 굽기` 를 한 번 돌리면 원본에서 본을 베껴 **에셋(.meta)에**
구워 넣는다 — 재임포트·재시작에도 유지된다. 아트 쪽에서 따로 할 일은 없다.

**⚠️ 좌우가 갈리는 부위는 파일이 두 장이다.** 어깨·손·발·소매·바지다리는 뼈 이름이
`bone_arm_R` / `bone_arm_L` 처럼 달라서 같은 스프라이트를 양쪽에 못 쓴다
(SpriteSkin 이 **이름으로** 뼈를 찾는다). 설치 도구가 `이름@L.png` 를 자동으로
복사해 각각 제 뼈로 굽는다 — 그림은 한 장만 그리면 된다.

## 1. 무기 (WeaponR)

세워서 뽑고 **반시계 +60°** 회전해 눕힌다 → 날이 좌상단, 자루가 우하단 (주축 −30°).
본 가중치가 없어도 손뼈의 자식이라 그냥 따라간다.

| 종류 | 긴 변 | 원본 근거 | 형태 지시 |
|---|---|---|---|
| 검 (jian) | **150** | 0007=145, 0014=173 | 곧은 양날, 짧은 코등이, 술 없음 |
| 도 (dao) | **150** | 위와 같은 급 | 한쪽 날, 완만한 곡선, 끝이 넓어짐 |
| 창·곤 | **205** | 0004=201, 0019=206 | 자루가 전체의 3/4, 날은 짧게 |
| 기병(단검·부채·아미자) | **105** | 0001=85, 0017=106 | 손에 감기는 작은 물건 |
| 권갑 | **90** | 0008=68, 0012=89 | 팔뚝 보호대, 손은 그리지 않음 |

## 1-b. 방어구는 '긴 변'이 아니라 **박스**로 맞춘다

긴 변만 맞추면 세로로 긴 그림이 몸보다 길쭉해진다(실측: 조끼가 몸통보다 높고 좁게 붙었다).
`tools/fit_wear.py` 의 `KIND_BOX` 가 부위별 박스이고, 비율이 안 맞으면 **1.35배까지만**
눌러서 채운다. AI는 사람 등신으로 그리고 SP1 파츠는 등신이 낮아서, 조금 눌러야 붙는다.

| 부위 | 박스 (가로×세로) | 근거 |
|---|---|---|
| 투구 | **145×80** | 아래 2번 |
| 몸통 | 76×71 | 원본 60×47~78×73 |
| 어깨 | 40×40 | 원본 27~44 |
| 손 | 38×39 | 원본 38×39 |
| 발 | 36×36 | 원본 36×29, 부츠는 세로가 커진다 |
| 허리 | 60×44 | 원본 60×44 |
| 목 | 52×34 | 원본 52×31 |
| 소매 | 43×42 | 원본 41×41 |
| 바지 허리 | 60×34 | 원본 60×25 (치마형이라 조금 여유) |
| 바지 다리 | 36×33 | 원본 34×31 |

원본은 다시 뽑지 않아도 되게 `tools/_wear_src/` 에 보관된다. fit 을 두 번 돌려도
축소가 겹치지 않는다.

## 2. 투구 · 머리 (Hat)

**세로는 80을 넘기지 않는다.** 원본 투구는 145×144까지 크지만 얼굴 자리에 **눈구멍이
뚫려 있어서** 머리를 다 덮어도 얼굴이 보인다. 우리 그림은 통짜라 같은 크기로 덮으면
눈이 사라진다(실측: 투구 아랫변이 눈보다 0.27유닛 아래였다).

**높이가 달라도 윗변을 맞춘다.** 원본 투구 16종의 윗변은 전부 `bone_head` 위 1.13~1.25
에 몰려 있고 아랫변은 −0.20~+0.56 로 제각각이다. 중앙값 하나로 다 붙이면 낮은 모자는
머리에 파묻히고 높은 모자는 뜬다 → 본 굽는 도구가 윗변 기준으로 맞춘다
(`WuxiaBoneBaker.TopAligned`). 몸통 갑옷도 같다 (원본 6종 윗변이 전부 0.425).

| 형태 | 눈까지 내려오는가 | 비고 |
|---|---|---|
| 두건 · 머리띠 | ✕ (이마 위) | 세로가 짧다 |
| 삿갓 | ✕ (챙이 옆으로) | 챙 때문에 가로가 최대치 |
| 유건 · 복두 | 살짝 | 옆에 각진 날개 |
| 도관 · 관 | ✕ (정수리) | 세로로 솟음, 비녀가 옆으로 |
| 투구 (전립·주립) | **○ 눈높이까지** | 원본 0019가 이 형태 |

## 3. 몸통 (Armor)

| 항목 | 값 |
|---|---|
| 긴 변 | **76** (원본 60×47 ~ 78×73, 중앙 76×71) |
| 실제 형태 | **전신 옷이 아니다.** 가슴~허리만 덮는 작은 조각 |

소매·어깨·목·허리는 **전부 다른 슬롯**이다. 도포 한 벌을 원하면 조각으로 나눠 그린다.

| 형태 | 구분 |
|---|---|
| 긴팔 | 몸통 조각에 소매를 그리지 않는다 — 소매는 `ArmorArm` 슬롯이 맡는다 (아래 8번) |
| 짧은팔 · 민소매 | 몸통 조각만으로 충분 |
| 갑주 | 판금 조각을 겹쳐 그리되 세로 76px 안에서 읽히게 |
| 도포 · 장삼 | 앞섶 여밈선 하나로 표현. 무늬는 안 보인다 |

## 8. 소매 (ArmorArm) · 하의 (Pants)

한동안 "원본 파츠가 0개라 못 만든다"고 적어 두었는데 **틀렸다**. `_Fixed` 카테고리만
보고 판단한 결과였고, 실제 원본은 `_Main` 쪽에 있다:

| 카테고리 | 원본 | 뼈 |
|---|---|---|
| `ArmorArm_R_Main` / `ArmorArm_L_Main` | 각 5개 (본 4개) | `bone_arm_R` / `bone_arm_L` |
| `Pants_Pants_Main` | 6개 (본 4개) | `bone_body` |
| `Pants_R_Main` / `Pants_L_Main` | 각 4개 (본 2개) | `bone_leg_R` / `bone_leg_L` |

| 조각 | 파일 | 긴 변 | 형태 |
|---|---|---|---|
| 소매 | `sleeve_tN` (+`@L` 자동복사) | **43** (원본 30~43) | 위팔을 덮는 짧은 통. 손·어깨는 안 그린다 |
| 바지 허리 | `pants_tN` | **60** (원본 60×25) | 엉덩이만 덮는 납작한 띠. 다리는 안 그린다 |
| 바지 다리 | `pants_tN@leg` (+`@legL` 자동복사) | **36** (원본 30~36) | 허벅지~정강이 한 짝. 발·신발은 안 그린다 |

**바지 세 조각은 반드시 같은 티어 번호로 짝을 맞춘다.** 설치할 때 한 벌이 같은 인덱스를
받는데, `ChangeSlotItem` 은 슬롯의 모든 카테고리를 그 인덱스로 맞추고 없는 곳은 Empty로
만든다 — 허리만 있고 다리가 없으면 다리가 사라진다.

## 뽑은 뒤 절차

```bash
python tools/fit_wear.py Assets/_Project/Resources/ArmorParts   # 부위별 크기·회전·외곽선 자동
```
→ 에디터에서 `IdleMvp/아트/무협 파츠 설치`
→ `IdleMvp/아트/무협 방어구 본 굽기` (방어구만. 무기는 필요 없다)
→ Play 재시작

파일명이 곧 부위다: `hat_`, `armor_`, `shoulder_`, `glove_`, `shoes_`, `belt_`, `neck_`,
`sleeve_`, `pants_`(허리) / `pants_tN@leg`(다리).
`@L` · `@legL` 은 설치할 때 자동으로 복사되므로 직접 만들지 않는다.

관련: `tools/sp1-wear-reference.md` (무기 실측), `tools/sp1-armor-reference.md` (방어구 실측),
`Assets/_Project/Scripts/Progression/WuxiaPartRig.cs` (본 가중치 이식)
